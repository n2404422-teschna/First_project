# Урок 5: Щоденник програміста на віддаленці — Кава проти Сну

Навчальний проєкт із кількох файлів на Python для зчитування, перевірки даних та аналізу записів із CSV-файлу з використанням `pathlib` і власних винятків. Дані вигадані, без особистої інформації.

## Структура проєкту

- `main.py` — точка входу в програму
- `app/__init__.py` — ініціалізація пакета `app`
- `app/config.py` — шляхи до файлів через `pathlib` від `Path(__file__)`
- `app/exceptions.py` — власні винятки проєкту
- `app/data_loader.py` — зчитування та перевірка даних із CSV-файлу
- `app/services.py` — розрахунки та аналіз записів
- `data/work_log.csv` — дані для перевірки (10 рядків, включаючи рядки з навмисними помилками)
- `run_output.txt` — вивід трьох запусків програми
- `requirements.txt` — залежності проєкту
- `.gitignore` — файли та папки, які не відстежує Git

## Запуск

З кореня проєкту `Lesson_5_coffee_vs_sleep`:

python main.py
