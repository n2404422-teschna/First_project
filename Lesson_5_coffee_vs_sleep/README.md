# Урок 5: Дневник программиста на удаленке — Кофе против Сна

Навчальний проєкт для обробки даних із CSV-файлу з використанням `pathlib`, кастомних винятків та перевіркою записів.

## Структура проєкту

- `main.py` — точка входу в програму
- `app/config.py` — шляхи до файлів через `pathlib`
- `app/exceptions.py` — кастомні винятки проєкту
- `app/data_loader.py` — зчитування та валідація рядків із CSV
- `app/services.py` — аналіз записів, попередження та підсумки тижня
- `data/work_log.csv` — вхідні дані для перевірки

## Запуск

З папки проєкту `Lesson_5_coffee_vs_sleep`:

```bash
python main.py
