# Проблемний бриф: Облік видачі книжок у бібліотеці

### 1. Проблема
Бібліотекар не має зручного інструменту для швидкого підрахунку заборгованостей читачів, через що важко виявляти прострочені повернення.

### 2. Користувач
Координатор або бібліотекар навчальної бібліотеки.

### 3. Вхідні дані
Список із 8 записів (словників) про видачу книжок:
- id (int) — номер видачі
- service (str) — категорія / назва
- wait_days (int) — днів затримки
- resolved (bool) — чи повернуто (True/False)

### 4. Очікуваний результат
Три показники та мітка класифікації (швидко / нормально / довго):
1. Кількість видач.
2. Частка повернутих книжок, %.
3. Середня затримка, днів.
4. Класифікація: <=3 дні — "швидко", <=10 днів — "нормально", >10 днів — "довго".

### 5. Критерії успіху
Автоматичний розрахунок коду повністю збігається з ручним обчисленням на папері.

### Кроки реалізації та перевірки:
1. Створити список з 8 словників -> len(requests) == 8
2. Порахувати 3 показники -> порівняти з ручним розрахунком
3. Класифікувати через if/elif/else -> перевірити мітки
4. Написати функції та assert -> запуск без помилок

### Обмеження рішення
Код працює лише з фіксованим списком у програмі.
